# 启航AI工作台（Qihang AI Desktop）

> 一个**本地优先的个人 AI 工作台**：你的本地项目库（Markdown 笔记目录）是数据主体，AI 围绕它记笔记、找资料、跟任务、守日程、写日报；日常使用的 Claude Code、Codex、Trae、Qoder 等智能体，也在这里被统一观测、审批与检索。**开箱免费用，数据留本地，手机上指挥。**

![License](https://img.shields.io/badge/license-MIT-blue.svg)

> 功能使用说明见应用内「帮助」页（今天页、对话、任务、事项与工单、MCP、审批、手机访问等章节）；本机知识库 MCP 接入见 [docs/知识库MCP.md](docs/知识库MCP.md)，飞书开通步骤见 [docs/飞书连接指南.md](docs/飞书连接指南.md)，历次更新记录见 [docs/更新日志.md](docs/更新日志.md)。

## 项目说明

**项目就是本地目录**：每个「项目」指向你磁盘上的一个文件夹（笔记库 / 代码库 / 资料库都行），AI 对话按所选项目目录运行，直接读取、写入目录里的 Markdown 文件作答；飞书派活、任务结果存档默认写入默认项目。

- 📚 **项目库为主体**：多项目管理，AI 对话按项目目录运行，直接读写 Markdown 文件作答，不凭空瞎编
- 💬 **AI 对话**：pi / opencode 双引擎、多轮对话、图片识别、流式输出、模型切换；飞书 / 手机端无缝接续
- 📋 **任务中心**：定时/循环任务、执行历史、追问续跑，结果自动归档项目库
- 🧾 **事项与工单**：待办、工单、定时提醒统一入口——待办快速记录并同步笔记；工单支持类型/来源/项目/处理人/承诺时间/状态流转/自定义字段，处理人变更按节点 webhook 通知，流转节点账可回放，承诺时间到点自动提醒；AI 与飞书可直接建单、查单、改单
- 📅 **今天页**：一页聚合每日概览——昨日简报（AI 多 agent 分片生成，含 AI 动态、笔记动态与工单进展）、等你处理（本地待办 + 笔记待办，勾选即回写笔记）、AI 工具动态（实时探测 8 大智能体运行状态与活动时段）、工作日志（笔记库最近更新文档一键打开）
- 🕘 **会话档案与问雷达**：Claude Code / Codex / Trae / Qoder / opencode / DSH / pi 等智能体的对话统一采集沉淀本地，支持工具筛选、全文搜索（标题 + 正文、命中词高亮）、分页浏览；「问雷达」对历史对话溯源问答，答案带来源标注
- 🔌 **MCP 双向能力**：
  - 作为客户端接入外部 MCP 服务（Streamable HTTP），业务数据直接进入 AI 对话工具面；服务列表 / 详情按需读取，并支持只调用单个服务工具的「专属对话」
  - 作为服务端对外提供本机知识库 MCP（qihang-kb），把笔记库、已采集会话、应用内对话、历史报告以 5 个只读工具开放给外部智能体，一条配置即可接入
- 🛡️ **审批与通知**：Claude Code / OpenCode / pi / DSH 的敏感工具调用可推送飞书审批卡，回合完成/失败实时通知到飞书、桌面与手机
- 🔗 **飞书集成**：Bot 对话、卡片选项目、「接着问」续聊、定时日报推送、工单指派通知
- 📰 **自动日报**：每天定时汇总所有项目笔记、任务、对话，生成 AI 日报并推送（支持自定义提示词与模板）
- 🛠️ **技能（beta）**：演示大纲、周报日报、思维导图、文案、网站抓取、图片生成，历史记录可管理
- 📱 **随身可用**：frp 内网穿透 + 手机浏览器 H5，出差在外遥控家里电脑的 AI
- 🔒 **数据安全**：笔记、对话、待办、工单、采集数据全部存本机，不上传云端；本机 MCP 仅监听 127.0.0.1 并需 Token 鉴权

> 外部连接都是可选项：断开飞书、手机与 MCP，工作台依然完整可用。

## 快速开始

1. **安装启动**：双击安装包（pi 内核已内置，无需安装 Node 或任何 CLI）。
2. **设置项目**：「设置 → 📁 项目」，添加你的 Markdown 文件夹并设为默认——这是你的数据主体，之后所有对话、任务、日报都围绕它展开。
3. **配置模型**：「设置 → 💬 对话模型配置」，选「默认（DeepSeek）」只填 API Key，或「自定义」接任意 OpenAI 兼容接口。
4. **开始使用**：在「对话」页提问（AI 会直接读你的项目文件作答），「今天」页看待办与日报，「事项」页管理待办、工单与提醒，「任务」页建定时任务，「MCP」页接入外部 MCP 服务（可选）。
5. **连接手机（可选）**：配置飞书 Bot 在手机上下发任务、收日报；或开启「设置 → 📱 移动端」并配置 frpc，用手机浏览器直接访问工作台。

## 飞书使用指南

> 📖 **飞书没配过、不知道从哪开始？** 请看 [docs/飞书连接指南.md](docs/飞书连接指南.md)：两种接入方式的完整开通步骤、所需权限清单、卡片回调订阅与常见问题排查，一篇讲清。

### 1. Webhook 推送

粘贴飞书群机器人 Webhook 地址，AI 日报、提醒即可推送到群。

### 2. Bot 对话

在飞书开放平台创建应用，填 `App ID` / `App Secret`，启动后可在飞书私聊/群聊中直接使用 AI。

### 3. 卡片交互

- **项目选择卡片**：多项目时每条消息先弹「请选择项目」卡片，点按钮即指派；也可用 `/项目 名称`、`/项目 序号`、直接回复序号、消息开头写项目名或行内标记 `[笔记库：X]` 指定。
- **结果卡片**：执行结果标注「本条发到：X」，点「💬 接着问」可在飞书里继续该话题（同一会话续聊 30 分钟窗口），不点则每条消息都是新话题。
- **前置条件**：需在飞书开放平台为应用订阅「卡片回调」（`card.action.trigger`）事件；未订阅时按钮不可用，回复序号/指令仍然有效。

## 手机访问与内网穿透（frp）

出差不带电脑也能用：手机浏览器直接访问家里电脑上的工作台，对话、选项目、看历史都走 App 自带的本机网关。公网入口通过 [frp](https://github.com/fatedier/frp) 打通，**服务端装在云服务器，客户端由 App 托管**。

### 链路

```text
手机浏览器
   │  http(s)://<公网IP或域名>:18791
   ▼
frps（云服务器，常驻）
   ▲  出站长连接（7000）
   │
frpc（家里电脑，由 App 启动和守护）
   │
工作台本机网关 127.0.0.1:8791
```

- App 网关只监听 `127.0.0.1:8791`，不直接暴露到公网
- frpc 随 App 自启、异常退出自动重连（3s 起、最长 60s 退避），关闭 App 即断开
- 手机首次访问需输入配对码（6 位、5 分钟有效、一次性），换取该设备的随机 token

### 一、下载安装 frp

1. 打开 <https://github.com/fatedier/frp/releases>，下载对应平台的发行包（以 `frp_0.72.0` 为例）
   - Windows（家里电脑）：`frp_0.72.0_windows_amd64.zip`
   - Linux（云服务器）：`frp_0.72.0_linux_amd64.tar.gz`
2. 解压后只需要 `frpc`/`frpc.exe`、`frps`/`frps.exe` 和各自的 `*.toml` 配置文件，其余可删。

### 二、服务端 frps（云服务器）

1. 把 `frps` 与 `frps.toml` 上传到服务器，例如 `/opt/frp/`
2. `frps.toml` 示例：

```toml
bindPort = 7000
# 鉴权 token，客户端必须一致，请改成你自己的强随机串
auth.token = "YOUR_STRONG_TOKEN"

# 可选：管理面板（建议只绑 127.0.0.1，通过 SSH 隧道查看）
webServer.addr = "127.0.0.1"
webServer.port = 7500
```

3. 放行端口：云厂商安全组和系统防火墙都要放行 `7000`（frps 控制端口）和 `18791`（对外映射端口）
4. 启动：
   - Linux：`chmod +x frps && ./frps -c frps.toml`
   - Windows：`frps.exe -c frps.toml`
5. 常驻用 systemd（可选）：

```ini
[Unit]
Description=frps
After=network.target

[Service]
Type=simple
ExecStart=/opt/frp/frps -c /opt/frp/frps.toml
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now frps
```

### 三、客户端 frpc（运行工作台的电脑）

`frpc.toml` 示例，端口与工作台默认网关一致：

```toml
serverAddr = "你的云服务器IP"
serverPort = 7000
auth.token = "YOUR_STRONG_TOKEN"

[[proxies]]
name = "qihang-mobile"
type = "tcp"
localIP = "127.0.0.1"
localPort = 8791
remotePort = 18791
```

### 四、在 App 内开启（推荐，不用手动跑 frpc）

1. 「设置 → 📱 移动端」打开「启用移动端网关」，端口保持 `8791`
2. 在「🔗 frpc 内网穿透」中：
   - **frpc 程序路径**：选择 `frpc.exe` 实际位置
   - **frpc 配置文件**：选择上面的 `frpc.toml`
   - 勾选「随 App 启动 frpc」，点「应用 / 重启」
3. 状态区显示「运行中 + PID」即成功；App 退出时会一并关闭 frpc
4. 点「生成配对码」，手机打开 `http://<公网IP>:18791/`，输入 6 位配对码绑定

之后每次启动 App，网关和 frpc 都会自动拉起，无需再手动运行或保留终端脚本。

### 五、安全建议

- `frpc.toml` 属于本机私密配置，不要提交到仓库（本文档中的 token 一律为占位符）
- 公网 `18791` 适合联调期；长期方案建议域名 + HTTPS（nginx 反代到 18791），随后关闭公网端口
- 手机丢失或更换：清空 `~/.qihang-ai-desktop/mobile-devices.json` 可撤销全部配对设备，再重新生成配对码

### 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 设置页 frpc 显示未运行 | 程序或配置文件路径不存在 | 检查两个路径是否存在，查看日志中的 `[Frpc]` 行 |
| 日志 `token in login doesn't match` | 客户端与服务端 token 不一致 | 两端 `auth.token` 保持一致后重启 |
| 日志 `port already used` | `remotePort` 被其他进程占用 | 改 `remotePort`，或停掉占用进程 |
| 手机打不开页面 | 端口未放行或 frpc 未连上 | 先测 `http://IP:18791/api/health`，再查安全组/防火墙 |
| frpc 反复重启 | 网络抖动或地址错误 | App 会自动退避重连；持续失败看设置页 `lastError` |

## 配置指南

### 1. AI 模型

- **默认（DeepSeek）**：只需填 API Key 即可快速开始
- **自定义**：任意 OpenAI 兼容接口（DeepSeek、Ollama、LM Studio 等），填 Base URL / API Key / 模型名，可配多个 Provider、多个模型，对话页随时切换

### 2. 网络搜索

- **自动引擎（默认）**：免费可用，百度 / Bing / DuckDuckGo 自动降级
- **增强（可选）**：配置博查或 Serper 的 API Key，更稳定、中文效果更好

### 3. 飞书

- 飞书 Webhook（群推送）与飞书 Bot（应用凭据）互相独立，可任选或同时开启
- 卡片按钮需在飞书开放平台订阅「卡片回调」事件

### 4. 任务

- 「任务」页创建任务，支持立即、指定时间或定时循环触发，结果保存到项目库，可选推送飞书

### 5. 事项与工单

- 「事项」页统一管理待办、工单与定时提醒：待办回车即建并同步笔记；工单支持类型/来源/项目/处理人/承诺时间/状态流转与自定义字段
- 「工单设置」维护类型、来源、项目、状态枚举与自定义字段；状态链为待处理 → 处理中 →（自定义流转态）→ 已完成 → 已关闭，自定义状态可标记为终态
- 「处理人节点」= 名字 + webhook：工单处理人填了/改了谁，匹配到节点就通知谁；未匹配时降级到全局飞书 Webhook
- 工单承诺时间会自动派生系统提醒（终态停提醒、改期顺延）；关联待办随工单终态自动收尾、退回自动复活
- 对话里可直接说「帮我记个工单 / 查一下某项目的工单」，AI 通过 `create_ticket` / `query_tickets` / `update_ticket` 读写工单；飞书「帮我记录」也直接落工单

### 6. 数据备份

- 「设置 → 💾 数据备份与恢复」一键备份、开启每日自动备份（保留最近 N 份）、从备份文件一键恢复（恢复后重启应用生效）

## 数据与隐私

- 所有数据保存在本机：SQLite 数据库（`~/.qihang-ai-desktop/qihang-ai-desktop.db`）与你的项目文件夹。
- 对话内容默认会发送给你所配置的模型服务商用于生成回复。
- 如需**完全离线**：对话模型配置为 Ollama 本地模型即可（此时除软件自动更新外无任何网络请求）。
- 飞书凭据等敏感配置保存在本机 `config.json`（已加入 `.gitignore`，不会进入仓库）。

## 常见问题（FAQ）

**Q：首次对话提示需要配置模型？**
A：在「设置 → 💬 对话模型配置」填 API Key（默认 DeepSeek）或自定义 OpenAI 兼容接口，点「测试」验证。

**Q：AI 答非所问，没有用到我的笔记？**
A：检查「设置 → 📁 项目」是否已添加并选中目标项目；对话页顶部可切换会话所属项目。

**Q：飞书卡片按钮点了没反应？**
A：需在飞书开放平台为应用订阅「卡片回调」（`card.action.trigger`）事件并重新发布版本；未订阅时直接回复序号或 `/项目 N` 同样有效。完整排查见 [docs/飞书连接指南.md](docs/飞书连接指南.md)。

**Q：飞书里怎么接着上一个话题聊？**
A：点击结果卡片上的「💬 接着问」进入续聊模式，之后直接回复即可；发 `/` 开头命令或点项目选择按钮则退出续聊开始新话题。

**Q：可以完全离线使用吗？**
A：可以。对话模型配置为 Ollama 本地模型即可，不开启飞书/联网搜索就没有任何外部依赖。

**Q：工单和待办有什么区别？**
A：待办是「要动手的事」，勾掉即完成并同步笔记；工单是「要跟进的事」，带状态流转、处理人、承诺时间与流转节点账。两者同表存储、在「事项」页分开显示，待办本质是类型为「待办」的工单。

**Q：工单改了处理人，对方没收到通知？**
A：到「事项 → 工单设置 → 处理人节点」确认处理人名字与节点完全一致、节点已启用且 webhook 可访问；未匹配到节点时会降级到「设置 → 飞书 Webhook」的全局地址。

**Q：数据会丢失吗？**
A：数据保存在本机数据库，正常退出不丢失。可在「设置 → 数据备份与恢复」一键备份、开启每日自动备份（保留最近 N 份），或从备份文件一键恢复（恢复后重启应用生效）。

## 开发者指南

### 环境要求

- Node.js 22.19+（pi agent SDK 的硬性要求；Electron 39 内置 Node 22.22，开发用的命令行 Node 建议同版本）
- Electron 39（应用内已固定，**不要单独升级/降级**；升级后必须 `npx electron-rebuild -f -w better-sqlite3` 重编原生模块）
- 可选：Ollama（本地对话模型）

### 开发调试

```bash
npm install            # 安装依赖（含 Electron 原生模块编译）
npm run dev            # 编译主进程 + 启动 Vite 开发服务器 + 启动 Electron
npm run dev:web        # 仅启动 Vite 前端（纯浏览器预览，带示例数据垫片，不开 Electron）
```

### 测试

```bash
npm run test:router    # 飞书多项目路由单元测试（103 条断言）
```

### 构建

```bash
npm run build            # vite build + tsc 编译 + electron-builder 完整打包
npm run build:web        # 仅构建前端产物（不打包安装程序）
```

### 项目结构

```
├── electron/          # Electron 主进程
│   ├── main.ts        # 入口：窗口、IPC、飞书、定时任务接线
│   ├── preload.ts     # 渲染进程桥接（contextBridge）
│   └── services/      # 核心服务
│       ├── pi-agent.ts      # AI 引擎：模型注册/会话/流式输出/customTools/MCP 扩展挂载
│       ├── mcp-manager.ts  # MCP 服务端（qihang-kb）/ 客户端（外部服务、工具清单、按需拉数）
│       ├── tools.ts         # 本地工具（项目文件/搜索/对话/提醒/任务/工单查询）
│       ├── tickets.ts       # 工单专表服务（字段归一、状态时间戳、onSave 钩子链）
│       ├── ticket-flow.ts   # 工单流转：处理人节点、节点账、处理人变更通知
│       ├── ticket-link.ts   # 工单承诺时间 → 提醒派生与终态收尾
│       ├── ai-tools.ts      # 技能工具（演示/日报周报/思维导图/文案/抓取/图片）
│       ├── feishu.ts        # 飞书 WebSocket 长连接 / Webhook / 卡片交互
│       ├── feishu-router.ts # 飞书多项目路由（指令解析/会话绑定/项目选择卡片）
│       ├── task-runner.ts   # 飞书任务记录与追问续跑
│       ├── scheduler.ts     # 定时任务调度器
│       ├── project-scan.ts  # 项目目录实时扫描（概览统计口径）
│       ├── note-digest.ts   # 笔记提炼（待办/跟进/工作日志提取）
│       ├── database.ts      # SQLite 本地数据库
│       ├── backup.ts        # 数据备份与恢复
│       ├── search.ts        # 联网搜索（自动引擎/博查/Serper）
│       └── agent-versions.ts   # 引擎版本信息
└── src/               # 渲染进程（Vue 3）
    ├── views/         # 页面（今天/对话/任务/事项/笔记/MCP/技能/设置/日志/帮助）
    ├── components/    # 组件（AppSidebar 侧边栏外壳 / TicketFormModal 工单编辑 / McpChatPanel 专属对话 等）
    ├── composables/   # 组合式函数（明暗主题等）
    └── router/        # 路由
```

> pi 引擎实现位于 `electron/services/pi-agent.ts`（opencode 作为外部引擎按需切换）；内置工具以 customTools 直接注入，外部系统经 MCP 接入同一工具面（在 MCP 页配置）。历次改动见 [docs/更新日志.md](docs/更新日志.md)。
