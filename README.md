# 启航AI工作台（Qihang AI Desktop）

> 一个**围绕本地项目库工作的个人 AI 智能体**：对话即查、任务即执行、数据即分析，你的 Markdown 笔记目录是数据主体。**开箱免费用，数据留本地，手机上指挥。**

## 定位：围绕本地项目库的个人 AI 智能体

**项目就是本地目录**：每个「项目」指向你磁盘上的一个文件夹（笔记库 / 代码库 / 资料库都行），AI 对话按所选项目目录运行，直接读取、写入目录里的 Markdown 文件作答；综合日报聚合所有项目 + 数据集；飞书派活、任务结果存档默认写入默认项目。

| 支柱 | 一句话 | 对应功能 |
|------|--------|----------|
| 📁 **主体：本地项目库** | Markdown 目录即数据主体，AI 直接读写 | 项目库 / 笔记 / 今天页 |
| 🧠 **智能面：助理 + 数据分析** | 对话、待办、提醒 + 数据集分析、日报报告 | 对话 / 任务 / 数据 / 技能 |
| 📶 **触达面：飞书 + 手机** | 移动指挥与推送回路，可断开不影响主功能 | 飞书 Bot / 中继 / 日报 |

> 触达面是场景包，不是前提：断开一切外部连接，工作台依然完整可用。

## ✨ 核心卖点

**1. 项目库为中心的自动化链路**

```
笔记 → 分析 → 建议 → 执行 → 推送 → 回到笔记
```

1. **笔记**：Markdown 随手记，JSON 数据批量导入数据集，各项目目录即数据主体。
2. **分析**：AI 直接读项目文件回答提问、查数据集，而不是凭空瞎编。
3. **建议**：AI 不只回答问题，还给出可执行建议——该做的事、该记的档。
4. **执行**：对话落成定时/循环任务和数据集记录，AI 用原生 `read`/`bash`/`write` 直接操作项目文件。
5. **推送**：定时提醒、每日 AI 日报，通过飞书推送到你的群和联系人；结果最终都归档回项目库。

**2. 深项目库架构**：项目库的检索与读写交给 AI agent 自己完成——工作台不再维护笔记工具层和向量索引，AI 用自带的 `read`/`bash`/`write` 按 `AGENTS.md` 约定直接操作项目目录；概览统计走实时扫盘，项目库里有什么，数字就是什么。

**3. 本地优先**：数据集、对话记录全部留在本机 SQLite，项目库就是你磁盘上的文件夹，随时可用任何编辑器打开、随时带走。

**4. 单引擎架构**：pi 引擎（`@earendil-works/pi-coding-agent`）直接运行在主进程内，对话、飞书、任务、日报、技能共用一条链路；本地工具以 customTools 原生注入，无子进程、无需安装 CLI。

**5. 手机指挥双通道**：飞书 Bot 一等入口——卡片选项目、接着问续聊、收日报；手机 App 经中继服务直连桌面端，完整对话与浏览历史。笔记本合盖在外面，手机照样指挥。

**6. 全新 UI**：固定侧边栏一天视角——「今天」总览、对话、任务、待办、笔记、数据一键直达；明暗主题切换；任意页面一键新开对话草稿；侧栏实时显示引擎与飞书服务状态。

## 快速开始

1. **安装启动**：双击安装包（pi 内核已内置，无需安装 Node 或任何 CLI）。
2. **设置项目**：「设置 → 📁 项目」，添加你的 Markdown 文件夹并设为默认——这是你的数据主体，之后所有对话、任务、日报都围绕它展开。
3. **配置模型**：「设置 → 💬 对话模型配置」，选「默认（DeepSeek）」只填 API Key，或「自定义」接任意 OpenAI 兼容接口。
4. **开始使用**：在「对话」页提问（AI 会直接读你的项目文件作答），「今天」页看待办与日报，「任务」页建定时任务，「数据」页管数据集。
5. **连接手机（可选）**：配置飞书 Bot 或中继连接，在手机上下发任务、收日报、继续对话。

## 飞书使用指南

> 📖 **飞书没配过、不知道从哪开始？** 请看 [docs/飞书连接指南.md](docs/飞书连接指南.md)：两种接入方式的完整开通步骤、所需权限清单、卡片回调订阅与常见问题排查，一篇讲清。

### 1. Webhook 推送

粘贴飞书群机器人 Webhook 地址，AI 日报、提醒即可推送到群。

### 2. Bot 对话

在飞书开放平台创建应用，填 `App ID` / `App Secret`，启动后可在飞书私聊/群聊中直接使用 AI。

### 3. 卡片交互

- **项目选择卡片**：多项目时每条消息先弹「请选择项目」卡片，点按钮即指派；也可用 `/项目 名称`、`/项目 序号`、直接回复序号、消息开头写项目名或行内标记 `[笔记库：X]` 指定。
- **结果卡片**：执行结果标注「本条发到：X」，点「💬 接着问」可在飞书里继续该话题（同一会话续聊 30 分钟窗口），不点则每条消息都是新话题。
- **前置条件**：需在飞书开放平台为应用订阅「卡片回调」（`card.action.trigger`）事件；未订阅时按钮不可用，回复序号/指令仍然有效。

## 手机 App 远程对话（中继连接）

桌面端与手机都躲在 NAT 后面，两者各自出站拨到同一个中继服务，按设备配对码对接：

1. 「设置 → 📱 移动端 → 📶 中继连接」填入中继服务地址，设置连接密码，开启允许移动端连接。
2. 手机 App 填同一中继地址与密码完成配对，即可远程对话、浏览会话历史与任务状态。
3. 桌面端只作 WS 客户端出站连接，不监听任何端口；桌面关机时手机端看到的是中继里的只读镜像（能看不能发）。

## 配置指南

### 1. AI 模型

- **默认（DeepSeek）**：只需填 API Key 即可快速开始
- **自定义**：任意 OpenAI 兼容接口（DeepSeek、Ollama、LM Studio 等），填 Base URL / API Key / 模型名，可配多个 Provider、多个模型，对话页随时切换

### 2. 网络搜索

- **自动引擎（默认）**：免费可用，百度 / Bing / DuckDuckGo 自动降级
- **增强（可选）**：配置博查或 Serper 的 API Key，更稳定、中文效果更好

### 3. 飞书与移动端

- 飞书 Webhook（群推送）、飞书 Bot（应用凭据）与中继连接（手机 App）互相独立，可任选或同时开启
- 卡片按钮需在飞书开放平台订阅「卡片回调」事件

### 4. 任务与日报

- 「任务」页创建任务，支持立即、指定时间或定时循环触发，结果保存到项目库，可选推送飞书
- 「设置 → 📊 综合日报设置 / 🤖 日报 AI 提示词」管理每日日报的保留天数、生成提示词与输出模板

### 5. 数据备份

- 「设置 → 💾 数据备份与恢复」一键备份、开启每日自动备份（保留最近 N 份）、从备份文件一键恢复（恢复后重启应用生效）

## 数据与隐私

- 所有数据保存在本机：SQLite 数据库（`~/.qihang-ai-desktop/qihang-ai-desktop.db`）与你的项目文件夹；设备配对凭证单独存于 `~/.qihang-ai-desktop/relay-device.json`。
- 对话内容默认会发送给你所配置的模型服务商用于生成回复。
- 如需**完全离线**：对话模型配置为 Ollama 本地模型即可（此时除软件自动更新外无任何网络请求）。
- 飞书凭据等敏感配置保存在本机 `config.json`（已加入 `.gitignore`，不会进入仓库）。
- 启用**中继连接**后，手机与桌面端的数据经中继服务中转；桌面端离线时手机看到的是中继里的只读镜像（能看、不能发）。请自行选择可信的中继服务地址。

## 常见问题（FAQ）

**Q：首次对话提示需要配置模型？**
A：在「设置 → 💬 对话模型配置」填 API Key（默认 DeepSeek）或自定义 OpenAI 兼容接口，点「测试」验证。

**Q：AI 答非所问，没有用到我的笔记？**
A：检查「设置 → 📁 项目」是否已添加并选中目标项目；对话页顶部可切换会话所属项目。

**Q：飞书卡片按钮点了没反应？**
A：需在飞书开放平台为应用订阅「卡片回调」（`card.action.trigger`）事件并重新发布版本；未订阅时直接回复序号或 `/项目 N` 同样有效。完整排查见 [docs/飞书连接指南.md](docs/飞书连接指南.md)。

**Q：飞书里怎么接着上一个话题聊？**
A：点击结果卡片上的「💬 接着问」进入续聊模式，之后直接回复即可；发 `/` 开头命令或点项目选择按钮则退出续聊开始新话题。

**Q：可以完全离线使用吗？**
A：可以。对话模型配置为 Ollama 本地模型即可，不开启飞书/中继/联网搜索就没有任何外部依赖。

**Q：数据会丢失吗？**
A：数据保存在本机数据库，正常退出不丢失。可在「设置 → 数据备份与恢复」一键备份、开启每日自动备份（保留最近 N 份），或从备份文件一键恢复（恢复后重启应用生效）。

## 开发者指南

### 环境要求

- Node.js 22.19+（pi agent SDK 的硬性要求；Electron 39 内置 Node 22.22，开发用的命令行 Node 建议同版本）
- Electron 39（应用内已固定，**不要单独升级/降级**；升级后必须 `npx electron-rebuild -f -w better-sqlite3` 重编原生模块）
- 可选：Ollama（本地对话模型）

### 开发调试

```bash
npm install            # 安装依赖（含 Electron 原生模块编译）
npm run electron:dev   # 编译主进程 + 启动 Vite 开发服务器 + 启动 Electron
```

### 测试

```bash
npm run test:router    # 飞书多项目路由单元测试（103 条断言）
```

### 构建

```bash
npm run electron:build   # vite build + tsc 编译 + electron-builder 打包
```

### 项目结构

```
├── electron/          # Electron 主进程
│   ├── main.ts        # 入口：窗口、IPC、飞书、定时任务、中继接线
│   ├── preload.ts     # 渲染进程桥接（contextBridge）
│   └── services/      # 核心服务
│       ├── pi-agent.ts      # AI 引擎：模型注册/会话/流式输出/customTools
│       ├── tools.ts         # 本地工具（数据集/项目文件/搜索/对话/提醒/任务查询）
│       ├── ai-tools.ts      # 技能工具（演示/日报周报/思维导图/文案/抓取/图片）
│       ├── feishu.ts        # 飞书 WebSocket 长连接 / Webhook / 卡片交互
│       ├── feishu-router.ts # 飞书多项目路由（指令解析/会话绑定/项目选择卡片）
│       ├── task-runner.ts   # 飞书任务记录与追问续跑
│       ├── relay-client.ts  # 移动端中继客户端（WS 出站 / 设备配对）
│       ├── relay-device.ts  # 中继设备身份与配对凭证
│       ├── scheduler.ts     # 定时任务调度器
│       ├── project-scan.ts  # 项目目录实时扫描（概览统计口径）
│       ├── note-digest.ts   # 笔记提炼（待办/跟进/工作日志提取）
│       ├── database.ts      # SQLite 本地数据库
│       ├── backup.ts        # 数据备份与恢复
│       ├── search.ts        # 联网搜索（自动引擎/博查/Serper）
│       ├── builtin-datasets.ts # 内置数据集模板
│       └── agent-versions.ts   # 引擎版本信息
└── src/               # 渲染进程（Vue 3）
    ├── views/         # 页面（今天/对话/任务/任务详情/待办/笔记/数据/技能/设置/日志/帮助）
    ├── components/    # 组件（AppSidebar 侧边栏外壳 / TreeNode / WelcomeGuide 等）
    ├── composables/   # 组合式函数（明暗主题等）
    └── router/        # 路由
```

> pi 引擎实现位于 `electron/services/pi-agent.ts`；内置工具以 customTools 直接注入，外部系统经 MCP 接入同一工具面（规划中）。历次改动见 [docs/更新日志.md](docs/更新日志.md)。
