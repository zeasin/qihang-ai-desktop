# 启航AI工作台（Qihang AI Desktop）

> 一个装在电脑上的**双面 AI 助手**：它既是**启航电商ERP 的电商智能助理**，也是**你的个人智能助理**——帮你记笔记、整理业务数据、管待办、写日报。**开箱免费用，数据留本地，手机上指挥。**

![License](https://img.shields.io/badge/license-MIT-blue.svg)

> 详细的功能设计与使用说明见 [docs/功能设计与使用说明.md](docs/功能设计与使用说明.md)。

---

## 两种身份

| 身份 | 说明 |
|------|------|
| 🏪 **电商智能助理** | 连接启航电商ERP 后解锁：查订单、析库存、商品分析、补货建议，对话即操作（主用户：中小电商卖家） |
| 🧑‍💻 **个人智能助理** | 不连 ERP 也完整可用：笔记知识库、业务数据整理（数据集）、待办任务、周期提醒、自动日报、AI 工具箱 |

> 个人助理不是"没连 ERP 的降级模式"，而是产品的独立价值面；连接 ERP 是叠加的电商场景包。

## ✨ 核心卖点

**1. 一条完整的自动化链路**

```
采集 → 分析 → 建议 → 执行 → 推送
```

1. **采集**：Markdown 笔记随手记，JSON 数据批量导入，自动归档进本地笔记库。
2. **分析**：AI 基于你的笔记、数据和 ERP 经营数据回答提问、查数据集，而不是凭空瞎编。
3. **建议**：AI 不只回答问题，还给出可执行建议——该做的事、该记的档、该补的货。
4. **执行**：对话落成定时/循环任务和数据集记录，AI 能读写笔记文件、操作本地数据。
5. **推送**：定时提醒、每日 AI 日报，通过飞书推送到你的群和联系人。

**2. 开箱即用**：AI 内核随应用内置（嵌入式 opencode），无需安装任何 CLI/Node；首次使用走 3 步免费模型引导，"配置自己的 API"是后置选项而非第一道门槛。

**3. 本地优先**：笔记、数据集、对话记录全部留在本机。

**4. 连接器架构**：工作台工具与外部系统（如启航电商ERP）统一走 MCP 接入，核心产品与场景解耦。

**5. 手机指挥**：飞书 Bot 是一等入口——手机下发任务、收日报、看分析、做确认。

## 快速开始

1. **安装启动**：双击安装包（AI 内核已内置，无需安装任何依赖）。
2. **模型引导（首启）**：推荐「免费开箱」——打开授权页 → 注册复制 Key → 粘贴回应用，约 1 分钟开始对话；也可在「设置 → 💬 对话模型配置」配置自己的 API（DeepSeek / Ollama / 任何 OpenAI 兼容接口）。
3. **设置笔记库**：「设置 → 📚 笔记库设置」，选择一个 Markdown 文件夹。
4. **开始使用**：在「AI」页对话（可切知识库/概览），「任务」页建定时任务，「数据」页管数据集。
5. **连接 ERP（可选）**：「设置 → MCP 服务器」填入启航电商ERP 的 MCP 地址与 Token，连接测试通过后即可对话查数、分析经营、生成补货建议。

## 飞书使用指南

### 1. Webhook 推送

粘贴飞书群机器人 Webhook 地址，AI 日报、提醒即可推送到群。

### 2. Bot 对话

在飞书开放平台创建应用，填 `App ID` / `App Secret`，启动后可在飞书私聊/群聊中直接使用 AI：随时提问、下发任务、接收日报——手机上就能指挥电脑里的 AI。

## 配置指南

### 1. AI 模型

- **免费开箱（推荐）**：首启引导完成 opencode 授权，即用免费模型
- **OpenAI 兼容接口**：DeepSeek、硅基流动等（内置快捷模板），填 API Base URL / API Key / 模型名
- **Ollama（本地/离线）**：填服务地址和模型名，完全离线可用

可配置多个接入、每个接入多个模型，对话页可随时切换。

### 2. AI 运行时与 ERP 连接

- 「设置 → AI 运行时」：查看引擎状态、重启 AI 服务、必要时切换回退引擎
- 「设置 → MCP 服务器」：ERP 连接（URL + Token + 连接测试）；工作台内置工具自动接入，无需配置

### 3. 任务与日报

- 「任务」页创建笔记任务，支持立即、指定时间或定时循环触发，结果保存到笔记库，可选推送飞书
- 「设置 → 综合日报设置 / 日报 AI 提示词」管理每日 AI 日报的保留天数与生成提示词

## 数据与隐私

- 所有数据保存在本机数据库（`~/.qihang-ai-desktop/qihang-ai-desktop.db`）与你的笔记文件夹中，不上传任何云端。
- 对话内容默认会发送给你所配置的模型服务商用于生成回复。
- 如需**完全离线**：对话模型配置为 Ollama 本地模型即可（除软件自动更新外无任何网络请求）。
- 飞书凭据、ERP Token 等敏感配置保存在本机 `config.json`（已加入 `.gitignore`，不会进入仓库）。

## 常见问题（FAQ）

**Q：首次对话提示需要配置模型？**
A：按首启引导完成免费模型授权（3 步），或在「设置 → 💬 对话模型配置」填写服务地址、API Key 和模型名称并点「测试」验证。

**Q：AI 答非所问，没有用到笔记？**
A：笔记库未设置。在「设置 → 📚 笔记库设置」选择包含 Markdown 文件的文件夹，重新提问。

**Q：连接 ERP 后 AI 查不到数据？**
A：在「设置 → MCP 服务器」对 ERP 行点「连接测试」；检查 URL 与 Token 是否正确、ERP 侧 MCP 服务是否启动。

**Q：可以完全离线使用吗？**
A：可以。对话模型配置为 Ollama 本地模型即可（连接 ERP 的局域网部署也不依赖外网）。

**Q：数据会丢失吗？**
A：数据保存在本机数据库，正常退出不丢失。可在「设置 → 数据备份与恢复」一键备份、开启每日自动备份（保留最近 N 份），或从备份文件一键恢复（恢复后重启应用生效）。

## 开发者指南

### 环境要求

- Node.js 18+
- 可选：Ollama（本地对话模型）

### 开发调试

```bash
npm install        # 安装依赖（含 Electron 原生模块编译）
npm run electron:dev   # 编译主进程 + 启动 Vite 开发服务器 + 启动 Electron
```

### 构建

```bash
npm run electron:build   # vite build + tsc 编译 + electron-builder 打包
```

### 项目结构

```
├── electron/          # Electron 主进程
│   ├── main.ts        # 入口：窗口、IPC、飞书、定时任务接线
│   ├── preload.ts     # 渲染进程桥接（contextBridge）
│   ├── worker/        # 数据库 Worker
│   └── services/      # 核心服务
│       ├── pi-agent.ts    # AI 引擎（pi）：模型注册/会话/流式输出（回退引擎）
│       ├── tools.ts       # 工具定义（笔记/数据集/提醒/任务/日报/搜索）
│       ├── ai-tools.ts    # AI 内容工具（演示/日报周报/思维导图/文案/抓取/图片）
│       ├── task-runner.ts # 飞书任务记录与追问续跑
│       ├── feishu.ts      # 飞书 WebSocket 长连接 / Webhook
│       ├── scheduler.ts   # 定时任务调度器
│       ├── rag.ts         # 笔记库语义检索
│       ├── indexer.ts     # 笔记库索引
│       ├── database.ts    # SQLite 本地数据库
│       ├── backup.ts      # 数据备份与恢复
│       ├── builtin-datasets.ts # 内置数据集模板
│       └── ...            # v2 规划：opencode 运行时/内嵌 MCP/ERP 连接
└── src/               # 渲染进程（Vue 3）
    ├── views/         # 页面（对话/任务/数据/提醒/工具箱/设置/日志/帮助）
    ├── components/    # 组件
    └── router/        # 路由
```

> v2 方向（嵌入式 opencode 底座 + ERP 连接）的实施细节见 `.trae/documents/opencode-integration-plan.md`。
