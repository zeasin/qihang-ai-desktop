# 启航AI工作台 —— 功能设计与使用说明（双引擎方案：pi + opencode）

> 本文档描述基于 **双 AI 引擎（pi 默认 + opencode 可选）** 的产品形态：面向启航电商ERP 用户的 AI 伴侣应用。包含功能设计、架构说明与完整使用指南。
>
> 配套文档：实施计划见 `.trae/documents/opencode-integration-plan.md`（含 POC 实测结论）。

## 1. 产品定位

**一个装在电脑上的双面 AI 助手：它既是启航电商ERP 的电商智能助理，也是你的个人智能助理——帮你记笔记、整理业务数据、管待办、写日报。开箱免费用，数据留本地，手机上指挥。**

| 身份 | 说明 |
|------|------|
| 🏪 电商智能助理 | 连接启航电商ERP 后解锁：查订单、析库存、商品分析、补货建议，对话即操作（主用户：中小电商卖家） |
| 🧑‍💻 个人智能助理 | 不连 ERP 也完整可用：笔记知识库、业务数据整理（数据集）、待办任务、周期提醒、自动日报、AI 工具箱 |

> 注意：个人智能助理不是"没连 ERP 的降级模式"，而是产品的独立价值面——数据整理、知识沉淀、日程管理、自动汇报，这一整套对任何人都成立；连接 ERP 是在此之上叠加的电商场景包。
>
> 产品关系：启航电商ERP 的 **AI 伴侣应用**——品牌与渠道附属 ERP，工程上独立安装、独立发版；对外名称「启航电商ERP AI 助手」（工程名 qihang-ai-desktop）。

### 与启航电商ERP 的关系

```
启航电商ERP（Java/Spring Boot）              启航AI工作台（Electron 桌面应用）
订单 / 商品 / 库存 / 采购 / 客户   ←─MCP─→   AI 对话 / 知识库 / 任务 / 数据集 / 日报
        │                                          │
        └─────── 品牌与渠道：ERP 的 README、文档、社区推广 ──────┘
```

- 两边各自独立安装、独立升级；工作台通过「连接 ERP」向导（MCP 地址 + Token）绑定
- 不连 ERP 时 = 通用本地 AI 助手，全部既有功能不受影响

## 2. 核心设计原则

| # | 原则 | 设计落点 |
|---|------|----------|
| 1 | **双引擎并存** | pi 为默认引擎（轻量稳定、本地工具全量可用），opencode 为可选引擎（免费模型、MCP 生态）；对话页一键切换，互为回退 |
| 2 | **用户零安装** | opencode 二进制随应用捆绑（electron-builder extraResources），主进程自动拉起 `opencode serve`，用户感知不到引擎差异，无需安装任何 CLI/Node |
| 3 | **本地优先** | 笔记、数据集、对话记录、会话历史全部留在本机 |
| 4 | **移动指挥** | 飞书 Bot 是一等入口：手机下发任务、收日报、看分析、做确认；无人值守场景固定走 pi 引擎（需要本地工具） |
| 5 | **连接器架构** | 外部系统（ERP 等）一律 MCP 接入；工作台本地工具 MCP 化后双引擎共享同一工具面（演进方向） |
| 6 | **开箱即用** | opencode 引擎提供免费模型 3 步引导；「配置自己的 API」始终是后置动作而非第一道门槛 |

## 3. 总体架构

```
┌───────────────────────── Electron 主进程 ─────────────────────────┐
│                                                                    │
│  5 个 agent 入口：主对话 / 飞书 Bot / 飞书追问 / AI 工具箱 / 定时日报 │
│        │                                                           │
│        ├─ 主对话 ──► 运行时选择器（config: agentRuntime）            │
│        │      ├─ 'pi'(默认) ────► pi 引擎                           │
│        │      │     customTools 原生注入（数据集/笔记/联网搜索）       │
│        │      └─ 'opencode' ──► opencode 适配层（runOc）             │
│        │            spawn serve 全托管：随机端口+健康检查              │
│        │            （2s×N 次探测 / 60s 启动上限 / 崩溃自愈）          │
│        │            ▼                                              │
│        │      opencode.exe serve（随应用捆绑，用户无感）              │
│        │            ├── 模型：自管 opencode.json（应用模型配置        │
│        │            │   自动同步）+ opencode 已授权模型（如 zhipuai）  │
│        │            ├── 每轮显式传模型、SSE 流式、POST 最终文本兜底     │
│        │            └── 单轮 180s 硬超时自动中止、全链路日志           │
│        │                                                           │
│        └─ 飞书 Bot / 飞书追问 / 定时日报 / AI 工具箱 ──► 固定走 pi    │
│                    （无人值守场景需要本地工具，不随运行时切换）         │
│                                                                    │
│  （演进）内嵌 MCP 服务：23 个本地工具暴露给 opencode；               │
│          ERP 走 remote MCP（Bearer Token）                          │
└────────────────────────────────────────────────────────────────────┘
```

**双引擎分工与回退**

| 维度 | pi 引擎（默认） | opencode 引擎（可选） |
|------|----------------|----------------------|
| 定位 | 轻量内置引擎，功能基线 | 功能引擎：免费模型、MCP 生态 |
| 本地工具 | customTools 原生（数据集/笔记/搜索）✅ | 暂无（待 MCP 化，规划中） |
| 飞书/定时任务/工具箱 | 承担 ✅ | 不参与 |
| 安装包体积 | 无增加 | +约 180MB（捆绑后） |
| 故障回退 | 任一引擎异常，对话页切换即用 | 同左 |

## 4. 功能设计

### 4.1 既有功能（个人智能助理能力面，全部保留）

> 以下模块构成「个人智能助理」的完整能力面：AI 帮你记笔记、整理业务数据、跟任务、守日程、写汇报——不需要连接任何外部系统。

| 模块 | 说明 |
|------|------|
| 💬 AI 对话 | 多轮对话、图片粘贴/上传识别、流式输出、模型与引擎切换；内含「对话 / 知识库 / 概览」三个 Tab |
| 📚 知识库 | 笔记库 Markdown 浏览预览、文件名搜索、基于笔记回答问题 |
| 📊 概览 | 统计卡片、综合日报、待办、提醒、待处理记录看板 |
| 🔔 任务中心 | 定时/循环任务（每天/每周/每月/Cron），结果自动存笔记库、可选推送飞书 |
| 🗃️ 数据集 | 多数据集、自定义 Schema、内置模板、AI 业务分析、JSON/URL 导入 |
| 📅 提醒 | 每日/每周/每月/每年/一次性提醒，系统通知 + 飞书推送 |
| 🔧 工具箱（beta） | PPT/HTML 演示大纲、周报日报、思维导图、文案、网站抓取、图片生成 |
| 🔗 飞书集成 | Webhook 推送；配置 Bot 后飞书内直接对话、下发任务 |
| 📋 自动日报 | 定时汇总笔记、任务、对话生成 AI 日报并推送 |

### 4.2 双引擎能力（✅ 已实现）

- **对话页引擎切换**：输入框左下角「pi 引擎 / opencode」下拉框，随时切换对比；切换自动重载模型列表，模型选择按引擎分别记忆
- **可用性检测默认引擎**：**应用每次启动主动检测 opencode 环境**（捆绑二进制或本机已安装）——检测到即默认 opencode，未检测到默认 pi；手动切换仅当前会话生效，重启后按环境重新判定
- **opencode 进程全托管**：懒启动（首次使用才拉起）、随机本地端口、健康检查、进程崩溃自愈、退出清理
- **自管配置**：应用「对话模型配置」自动同步进 opencode.json（OpenAI 兼容 provider 段 + 启航系统提示词）；修改模型配置自动生效；dev 配置于项目 `.qihang-oc/`（不入库），打包后于 `~/.qihang-ai-desktop/opencode/`
- **双引擎模型列表**：统一走 `pi:models` 接口按运行时分流；opencode 列表 = 应用已配置模型 + opencode 已授权模型（如 zhipuai）
- **可靠性**：health 探测 2s×N / 启动 60s 上限 / 会话创建 15s / 单轮对话 180s 硬超时自动中止；`[OcProcess]/[OcAgent]` 全链路日志
- **pi 零回归**：默认运行时仍是 pi，既有行为（含飞书、定时任务、工具箱）完全不变

### 4.3 演进能力（🚧 规划中）

#### 🤖 AI 运行时卡片（设置页增强）

- 服务状态徽标（健康 / 重启中 / 降级）与「重启 AI 服务」按钮
- 指数退避崩溃重启策略（连续 3 次失败进入降级态）

#### 🎁 模型引导（首启 Onboarding）

首次使用 opencode 引擎且无可用模型时，发消息触发引导横幅：

- **路径 A（默认推荐）：免费模型 3 步开箱**——打开授权页 → 注册复制 Key → 粘贴回填，自动刷新模型列表
- **路径 B：使用自己的 API**——跳转「对话模型配置」（OpenAI 兼容：DeepSeek、智谱、硅基流动、Ollama 等）

> 免费模型为官方限时供应，需一次账号授权（3 步），非完全零操作；可随时切换自有 API。

#### 🔌 MCP 服务器（新增设置卡片）

| 行 | 说明 |
|----|------|
| 工作台内置工具 | 23 个本地工具（笔记读写、数据集 CRUD、任务、提醒、联网搜索等）经内嵌 MCP 服务暴露——**MCP 化完成后 opencode 引擎即获得全部本地工具** |
| 启航电商ERP | 表单：URL + Token（Bearer）+ 启用开关 + 连接测试；测试通过后 ERP 工具自动进入 AI 可用列表 |

- 自定义 Header 勿填 `Accept` / `Content-Type` 等协议头（框架管理）
- Token 与模型 API Key 同等安全水位，明文存于本机 config.json

#### 🏪 ERP 连接向导

设置 → MCP 服务器 → 填 ERP 的 MCP 地址和 Token → 连接测试 → 完成绑定。绑定后即可在对话中查询与操作 ERP 数据（见 5.3 场景示例）。

## 5. 使用指南

### 5.1 安装与首次启动

1. 双击安装包安装（AI 内核已内置，无需安装 Node、CLI 或任何依赖）
2. 启动后完成两项基础配置：
   - **模型**：设置 → 💬 对话模型配置（OpenAI 兼容接口即可；opencode 免费模型引导上线后可跳过此步）
   - **笔记库目录**：设置 → 📚 笔记库设置，选择一个 Markdown 文件夹
3. 进入「AI」页开始对话；需要对比引擎时，在输入框左下角切换「pi 引擎 / opencode」

### 5.2 日常使用

**作为个人智能助理（不需要 ERP）：**

- 「把这段客户名单整理成数据集，字段：名称、地区、等级、跟进状态」→ AI 自动建数据集、逐条写入
- 「把我刚才说的这几件事记成待办，下周一开始跟进」→ 写入任务中心并设提醒
- 「读一下笔记库里上个月的周报，汇总成本月小结」→ 知识库检索 + 汇总成文
- 「每天晚上 9 点提醒我核对当天订单」→ 创建周期提醒
- 随手记的 Markdown 笔记、粘贴的 JSON 数据，都留在本机，AI 随时可查

**日常操作入口：**

- **对话**：AI 页输入问题，AI 按需自动调用本地工具（查数据集、读写笔记、联网搜索）后回答
- **知识库**：AI 页切到「知识库」Tab，让 AI 基于你的笔记回答
- **任务**：任务页创建定时/循环任务，结果自动落库并可推送飞书
- **数据集**：数据页管理结构化数据（客户、项目、Bug 等），AI 可直接查询与写入
- **提醒与日报**：提醒页设置周期提醒；每日日报自动汇总推送

> 引擎提示：涉及本地工具的任务（查数据集、读写笔记等）当前请使用 **pi 引擎**；opencode 引擎适合纯对话与写作类任务（本地工具 MCP 化后解除此限制）。

### 5.3 连接 ERP 后的场景示例（规划能力就绪后）

| 你说 | AI 做什么 |
|------|-----------|
| 「今天卖了多少钱？和昨天比呢？」 | 调 ERP 工具查当日/昨日销量，给出对比 |
| 「分析下滞销 SKU，给补货和下架建议」 | 查库存 + 销量 → 输出建议 → 可一键存为笔记或任务 |
| 「把这份分析推给我合伙人」 | 飞书卡片送达对方 |
| 「明早 9 点给我发昨日经营日报」 | 创建定时任务，到点自动执行并推送 |

### 5.4 手机指挥（飞书）

- 配置飞书 Bot 后（设置 → 飞书集成），在飞书里 @助手 即可：
  - 随时提问：「A 店铺近 7 天销量趋势？」
  - 下发任务：「整理本周客户跟进清单」
  - 接收日报、提醒与任务结果
- 飞书/定时任务固定走 pi 引擎，headless 已处理，AI 执行全程不弹审批阻塞

### 5.5 进阶：切换与排查

| 操作 | 入口 |
|------|------|
| 切换 AI 引擎 | **对话页输入框左下角**「pi 引擎 / opencode」下拉框（✅ 已上线） |
| 更换/新增模型 | 设置 → 💬 对话模型配置（OpenAI 兼容，可配多个接入；opencode 引擎自动同步） |
| 查看运行日志 | 日志页（LogView）过滤 `[OcProcess]` / `[OcAgent]`（opencode 链路）或 `[Pi]`（pi 链路） |
| AI 服务异常 | opencode 进程崩溃会自动重启；持续异常可切回 pi 引擎（互为回退） |

## 6. 方向自检：什么变了，什么没变

**变了（3 件事）**

1. 底座：单 pi → **双引擎并存**（pi 默认 + opencode 可选），对话页一键切换，互为回退
2. 获客逻辑：先配模型才能用 → 双引擎降低门槛（opencode 免费模型引导，规划中）
3. 定位：升级为**双面定位**——ERP 的电商智能助理 + 独立完整的个人智能助理（笔记、业务数据整理、待办、提醒、日报），连接 ERP 是叠加场景包而非前提

**没变（全部既有价值）**

数据闭环五步（采集→分析→建议→执行→推送）、本地优先、飞书集成、全部既有功能模块、独立应用形态、pi 引擎上的工具能力。

**需要接受的代价**

| 代价 | 说明 |
|------|------|
| 安装包 +约 180MB | opencode 二进制随包捆绑（约 200MB+ 总体积），换取安装即用与双引擎能力 |
| 版本跟随维护 | opencode 二进制与 SDK 同版本锁定（1.18.32），升级需一次完整回归验证 |
| 双引擎能力差异 | opencode 引擎当前无本地工具（MCP 化后解决）；飞书/定时任务固定走 pi |
| 国内网络依赖 | opencode 免费模型网关/授权页需可访问 opencode.ai；自有 API 不受影响 |
