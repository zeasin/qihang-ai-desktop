# 启航AI工作台 —— 功能设计与使用说明（opencode 方案）

> 本文档描述基于 **嵌入式 opencode 底座** 的产品形态：面向启航电商ERP 用户的 AI 伴侣应用。包含功能设计、架构说明与完整使用指南。
>
> 配套文档：实施计划见 `.trae/documents/opencode-integration-plan.md`。

---

## 1. 产品定位

**一个装在电脑上的双面 AI 助手：它既是启航电商ERP 的电商智能助理，也是你的个人智能助理——帮你记笔记、整理业务数据、管待办、写日报。开箱免费用，数据留本地，手机上指挥。**

| 身份 | 说明 |
|------|------|
| 🏪 电商智能助理 | 连接启航电商ERP 后解锁：查订单、析库存、商品分析、补货建议，对话即操作（主用户：中小电商卖家） |
| 🧑‍💻 个人智能助理 | 不连 ERP 也完整可用：笔记知识库、业务数据整理（数据集）、待办任务、周期提醒、自动日报、AI 工具箱 |

> 注意：个人智能助理不是"没连 ERP 的降级模式"，而是产品的独立价值面——数据整理、知识沉淀、日程管理、自动汇报，这一整套对任何人都成立；连接 ERP 是在此之上叠加的电商场景包。
>
> 产品关系：启航电商ERP 的 **AI 伴侣应用**——品牌与渠道附属 ERP，工程上独立安装、独立发版；对外名称「启航电商ERP AI 助手」（工程名 qihang-ai-desktop）。

### 与启航电商ERP 的关系

```
启航电商ERP（Java/Spring Boot）              启航AI工作台（Electron 桌面应用）
订单 / 商品 / 库存 / 采购 / 客户   ←─MCP─→   AI 对话 / 知识库 / 任务 / 数据集 / 日报
        │                                          │
        └─────── 品牌与渠道：ERP 的 README、文档、社区推广 ──────┘
```

- 两边各自独立安装、独立升级；工作台通过「连接 ERP」向导（MCP 地址 + Token）绑定
- 不连 ERP 时 = 通用本地 AI 助手，全部既有功能不受影响

## 2. 核心设计原则

| # | 原则 | 设计落点 |
|---|------|----------|
| 1 | **开箱即用** | 内置 opencode 免费模型网关；安装后 3 步引导即可开始对话，「配置自己的 API」是后置动作而非第一道门槛 |
| 2 | **用户零安装** | opencode 二进制随应用捆绑（electron-builder extraResources），启动时主进程自动拉起 `opencode serve`，用户感知不到底座存在，无需安装任何 CLI/Node |
| 3 | **本地优先** | 笔记、数据集、对话记录、会话历史全部留在本机 |
| 4 | **移动指挥** | 飞书 Bot 是一等入口：手机下发任务、收日报、看分析、做确认 |
| 5 | **连接器架构** | 一切外部系统走 MCP 接入；工作台自身工具同样 MCP 化，与外部连接器同一套语义 |
| 6 | **可回退** | AI 运行时可在 opencode / pi 之间切换（设置页一个开关），pi 引擎完整保留 |

## 3. 总体架构

```
┌───────────────────────── Electron 主进程 ─────────────────────────┐
│                                                                    │
│  5 个 agent 入口：主对话 / 飞书 Bot / 飞书追问 / AI 工具箱 / 定时日报 │
│        │                                                           │
│        ▼                                                           │
│  运行时选择器（config: agentRuntime = opencode | pi）               │
│    ├─ 'pi' ──────────► pi 引擎（原样保留，回退通道）                 │
│    └─ 'opencode'(默认) ─► opencode 适配层（会话/事件/超时映射）       │
│          │ spawn + 健康检查 + 崩溃自愈                               │
│          ▼                                                         │
│  opencode.exe serve（随应用捆绑，用户无感）                           │
│                                                                    │
│  内嵌 MCP 服务（工作台 23 个本地工具：笔记/数据集/任务/提醒/搜索…）     │
└────────────────────────────────────────────────────────────────────┘
            │ remote MCP                      │ remote MCP（Bearer Token）
            ▼                                 ▼
     opencode 内核                      启航电商ERP（Spring AI MCP server）
     ├── 模型：免费开箱模型 / 自配 API / 本地 Ollama
     ├── 权限：headless 全放行（无人值守不卡审批）
     └── 行为：内置启航系统提示词 + 工作区约束
```

## 4. 功能设计

### 4.1 既有功能（个人智能助理能力面，全部保留）

> 以下模块构成「个人智能助理」的完整能力面：AI 帮你记笔记、整理业务数据、跟任务、守日程、写汇报——不需要连接任何外部系统。

| 模块 | 说明 |
|------|------|
| 💬 AI 对话 | 多轮对话、图片粘贴/上传识别、流式输出、模型切换；内含「对话 / 知识库 / 概览」三个 Tab |
| 📚 知识库 | 笔记库 Markdown 浏览预览、文件名搜索、基于笔记回答问题 |
| 📊 概览 | 统计卡片、综合日报、待办、提醒、待处理记录看板 |
| 🔔 任务中心 | 定时/循环任务（每天/每周/每月/Cron），结果自动存笔记库、可选推送飞书 |
| 🗃️ 数据集 | 多数据集、自定义 Schema、内置模板、AI 业务分析、JSON/URL 导入 |
| 📅 提醒 | 每日/每周/每月/每年/一次性提醒，系统通知 + 飞书推送 |
| 🔧 工具箱（beta） | PPT/HTML 演示大纲、周报日报、思维导图、文案、网站抓取、图片生成 |
| 🔗 飞书集成 | Webhook 推送；配置 Bot 后飞书内直接对话、下发任务 |
| 📋 自动日报 | 定时汇总笔记、任务、对话生成 AI 日报并推送 |

### 4.2 新增能力（本次 opencode 方案）

#### 🤖 AI 运行时（新增设置卡片）

- 运行引擎单选：**opencode（默认）** / pi（回退）
- 服务状态徽标：健康 / 重启中 / 降级
- 「重启 AI 服务」按钮：修改配置后手动生效
- opencode 进程由应用全托管：随机本地端口、启动健康检查、崩溃自动重启（指数退避，连续 3 次失败进入降级态）、退出应用自动清理

#### 🎁 模型引导（首启 Onboarding）

首次使用时没有任何可用模型，发消息会触发引导横幅，两条路径：

- **路径 A（默认推荐）：免费模型 3 步开箱**
  1. 点击「打开授权页」→ 浏览器打开 opencode 授权页
  2. 注册/登录并复制 API Key
  3. 回到应用粘贴 Key → 自动写入、刷新模型列表并选中免费模型
- **路径 B：使用自己的 API**
  - 跳转「对话模型配置」，支持 OpenAI 兼容接口（DeepSeek、智谱、硅基流动、Ollama 本地模型等）

> 说明：opencode 免费模型需一次账号授权（3 步），非完全零操作；免费模型为官方限时供应，后续也可随时切换到自有 API。

#### 🔌 MCP 服务器（新增设置卡片）

| 行 | 说明 |
|----|------|
| 工作台内置工具 | 只读状态行：显示已桥接工具数（笔记读写、数据集 CRUD、任务、提醒、联网搜索等 23 个，经内嵌 MCP 服务暴露给 AI） |
| 启航电商ERP | 表单：URL + Token（Bearer）+ 启用开关 + 「连接测试」按钮；测试通过后 ERP 的订单/库存/商品等工具自动进入 AI 可用工具列表 |

- 自定义 Header 勿填 `Accept` / `Content-Type` 等协议头（由框架管理）
- Token 与现有模型 API Key 同等安全水位，明文存于本机 config.json

#### 🏪 ERP 连接向导

设置 → MCP 服务器 → 填 ERP 的 MCP 地址和 Token → 连接测试 → 完成绑定。绑定后即可在对话中查询与操作 ERP 数据（见 5.3 场景示例）。

## 5. 使用指南

### 5.1 安装与首次启动

1. 双击安装包安装（AI 内核已内置，无需安装 Node、CLI 或任何依赖）
2. 启动后完成两项基础配置：
   - **模型**：走首启引导（推荐免费开箱，约 1 分钟）
   - **笔记库目录**：设置 → 📚 笔记库设置，选择一个 Markdown 文件夹
3. 进入「AI」页开始对话

### 5.2 日常使用

**作为个人智能助理（不需要 ERP）：**

- 「把这段客户名单整理成数据集，字段：名称、地区、等级、跟进状态」→ AI 自动建数据集、逐条写入
- 「把我刚才说的这几件事记成待办，下周一开始跟进」→ 写入任务中心并设提醒
- 「读一下笔记库里上个月的周报，汇总成本月小结」→ 知识库检索 + 汇总成文
- 「每天晚上 9 点提醒我核对当天订单」→ 创建周期提醒
- 随手记的 Markdown 笔记、粘贴的 JSON 数据，都留在本机，AI 随时可查

**日常操作入口：**

- **对话**：AI 页输入问题，AI 按需自动调用本地工具（查数据集、读写笔记、联网搜索）后回答
- **知识库**：AI 页切到「知识库」Tab，让 AI 基于你的笔记回答
- **任务**：任务页创建定时/循环任务，结果自动落库并可推送飞书
- **数据集**：数据页管理结构化数据（客户、项目、Bug 等），AI 可直接查询与写入
- **提醒与日报**：提醒页设置周期提醒；每日日报自动汇总推送

### 5.3 连接 ERP 后的场景示例

| 你说 | AI 做什么 |
|------|-----------|
| 「今天卖了多少钱？和昨天比呢？」 | 调 ERP 工具查当日/昨日销量，给出对比 |
| 「分析下滞销 SKU，给补货和下架建议」 | 查库存 + 销量 → 输出建议 → 可一键存为笔记或任务 |
| 「把这份分析推给我合伙人」 | 飞书卡片送达对方 |
| 「明早 9 点给我发昨日经营日报」 | 创建定时任务，到点自动执行并推送 |

### 5.4 手机指挥（飞书）

- 配置飞书 Bot 后（设置 → 飞书集成），在飞书里 @助手 即可：
  - 随时提问：「A 店铺近 7 天销量趋势？」
  - 下发任务：「整理本周客户跟进清单」
  - 接收日报、提醒与任务结果
- 无人值守场景（飞书/定时任务）已做 headless 处理，AI 执行全程不会弹出审批阻塞

### 5.5 进阶：切换与排查

| 操作 | 入口 |
|------|------|
| 切换 AI 引擎 | 设置 → AI 运行时 → 单选 opencode / pi（切换自动重启服务，会话历史各自保留） |
| 更换/新增模型 | 设置 → 💬 对话模型配置（OpenAI 兼容，可配多个接入） |
| 重连/更换 ERP | 设置 → MCP 服务器 → 编辑 ERP 行 |
| AI 服务异常 | 设置 → AI 运行时 → 查看「重启 AI 服务」按钮；连续失败处于降级态时重启应用 |
| 查看运行日志 | 日志页（LogView）过滤 `[MCP]` / 运行时相关条目 |

## 6. 方向自检：什么变了，什么没变

**变了（3 件事）**

1. 底座：pi SDK → 嵌入式 opencode（用户无感，应用内可切回 pi）
2. 获客逻辑：先配模型才能用 → 免费开箱、后置配置
3. 定位：升级为**双面定位**——ERP 的电商智能助理 + 独立完整的个人智能助理（笔记、业务数据整理、待办、提醒、日报），连接 ERP 是叠加场景包而非前提

**没变（全部既有价值）**

数据闭环五步（采集→分析→建议→执行→推送）、本地优先、飞书集成、全部既有功能模块、独立应用形态。

**需要接受的代价**

| 代价 | 说明 |
|------|------|
| 安装包 +约 180MB | opencode 二进制随包捆绑（约 200MB+ 总体积），换取安装即用的确定性 |
| 免费模型需 3 步授权 | 非"绝对零配置"，onboarding 已做最小化引导 |
| 版本跟随维护 | opencode 二进制与 SDK 同版本锁定，升级需走一次完整回归验证 |
| 国内网络依赖 | 首次授权页/免费模型网关需可访问 opencode.ai，文档与错误文案提供代理设置说明 |
