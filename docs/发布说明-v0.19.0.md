# 启航AI工作台（Qihang AI Desktop）v0.19.0

一个**本地优先的个人 AI 工作台**：你的本地项目库（Markdown 笔记目录）是数据主体，
AI 围绕它帮你记笔记、找资料、跟任务、守事项、写简报；
你日常使用的 Claude Code、Codex、Trae、Qoder、MiniMax Code 等智能体，也在这里被统一观测、审批与检索。
开箱免费用，数据留本地，手机上指挥。

## 核心能力

- 📚 **项目库为主体**：多项目管理，AI 对话按项目目录运行，直接读写 Markdown 文件作答，不凭空瞎编
- 💬 **AI 对话**：pi / opencode 双引擎、多轮对话、图片识别、流式输出、模型切换；飞书 / 手机端无缝接续
- 📋 **任务中心**：定时/循环任务、执行历史、追问续跑，结果自动归档项目库；**每个任务独立选择使用的大模型，重跑时还可临时换**
- 🧾 **事项与工单**：待办、工单、定时提醒统一入口——待办快速记录并同步笔记；工单支持类型/来源/项目/处理人/承诺时间/状态流转/自定义字段，处理人变更按节点 webhook 通知，流转节点账可回放，承诺时间到点自动提醒；AI 与飞书可直接建单、查单、改单
- 📅 **今天页**：一页聚合每日概览——昨日简报（AI 多 agent 分片生成，含 AI 动态、笔记动态与工单进展；失败可现场换模型重试）、等你处理（本地待办 + 笔记待办，勾选即回写笔记）、AI 工具动态（实时探测 9 大智能体运行状态）、工作日志（笔记库最近更新文档一键打开）
- 🕘 **会话档案与问雷达**：Claude Code / Codex / Trae / Qoder / opencode / DSH / pi / **MiniMax Code** 等智能体的对话统一采集沉淀本地，支持工具筛选、全文搜索（标题 + 正文、命中词高亮）、分页浏览；「问雷达」对历史对话溯源问答，答案带来源标注
- 🔌 **MCP 双向能力**：
  - 作为客户端接入外部 MCP 服务（Streamable HTTP），业务数据直接进入 AI 对话工具面；**AI 数据分类点击时弹窗选模型**，并支持只调用单个服务工具的「专属对话」
  - 作为服务端对外提供本机知识库 MCP（qihang-kb），把笔记库、已采集会话、应用内对话、历史报告以 5 个只读工具开放给外部智能体，一条配置即可接入
- 🛡️ **审批与通知**：Claude Code / OpenCode / pi / DSH 的敏感工具调用可推送飞书审批卡，回合完成/失败实时通知到飞书、桌面与手机
- 🔗 **飞书集成**：Bot 对话（**可独立指定模型**）、卡片选项目、「接着问」续聊、定时提醒推送、工单指派通知
- 🛠️ **技能（beta）**：演示大纲、周报日报、思维导图、文案、网站抓取、图片生成，**生成时可选择本次使用的大模型**，历史记录可管理
- 📱 **随身可用**：frp 内网穿透 + 手机浏览器 H5，出差在外遥控家里电脑的 AI
- 🔒 **数据安全**：笔记、对话、待办、工单、采集数据全部存本机，不上传云端；本机 MCP 仅监听 127.0.0.1 并需 Token 鉴权

> 外部连接都是可选项：断开飞书、手机与 MCP，工作台依然完整可用。

## v0.19.0 更新亮点

- **模型选择全面场景化**：全局「后台任务模型」配置项拆解下线——昨日简报、会话摘要各有独立专项设置；定时任务在任务上选模型（重跑可临时换）；MCP 数据分类、工具箱技能改为使用时弹窗/下拉选；飞书 Bot 独立指定模型。未选择时统一回落 pi 默认模型
- **简报失败可换模型重试**：今天页昨日简报生成失败时完整显示错误，现场选个模型即可重跑，不用改设置
- **「默认」不再黑盒**：问雷达、新建对话、MCP 专属对话等所有模型下拉的「默认」选项直接显示当前实际使用的默认模型名
- **综合日报下线**：内置「生成综合日报」定时任务及其提示词/模板设置整体移除（历史日报数据启动时自动清理），今天页每日 AI 汇总统一由「昨日简报」承担
- **雷达接入 MiniMax Code**：mcode 会话采集（标题/项目/回合状态/完整正文），用户消息里的系统提示噪声自动剥离，不污染检索与摘要
- **今天页更清爽**：AI 工具动态去掉右侧「最近活动」面板，工具卡片整幅铺开；仪表盘接口同步减负
- **启动更快**：模型自愈与飞书 SDK 移出启动关键路径，冷启动不再等 SDK 加载
