# 2026-11-04 更新明细

## 智能体审批：雷达页内审批子功能（飞书兜底决策面）

### 目标
飞书不可用/离线时，在雷达页内直接决策挂起的审批。与飞书卡片共用同一 `ApprovalCenter` 状态机，决策结果双向一致（幂等）。

> 形态演进：初版把待审批面板嵌在雷达页「雷达已开启」分支内，导致雷达没开就看不到审批——与「审批通道独立于雷达」矛盾。随后一度改为侧边栏独立「审批」入口，但审批本质是雷达的子功能，不该占全局菜单。**最终：审批区块放在雷达页内、但在雷达开关分支之外**——雷达开没开，进入雷达页都能决策。

### 关键设计
- **审批是雷达子功能**：入口在雷达页，不占全局侧边栏菜单。
- **独立于雷达开关**：审批区块在雷达 `v-if/v-else` 分支之外——雷达没开也能在雷达页决策（审批通道独立于雷达采集内核）。
- **决策审计区分**：桌面决策 `by=desktop:local`，飞书决策 `by=feishu:<openId>`，`history.jsonl` 里可追溯来源。
- **幂等**：`resolve()` 先删 pending 再 resolve，双击第二次拿 `not_pending`，页面提示「已处理或已过期」。
- **不设超时**：沿用拍板——挂起一直等，直到有人决策或会话死亡按拒绝收口。
