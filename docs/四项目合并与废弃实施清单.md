```

  A1  M1→M2→M6（票据 + 飞书 + UI）           ← 可独立验收：造假票据走通卡片闭环

  B2  雷达监控 8 工具无回归（探针/入库/检索）

阶段 C｜归档（打包，不删）
  C1  D:/projects/_archive/2026-11-04/
        ├─ qihang-code-approver.tar.gz      （含最终 commit）
        ├─ AgentHub.tar.gz                  （含最终 commit）
        ├─ QihangAgentHub.tar.gz            （整目录，含唯一一份 approval-channels.md）
        ├─ mcp4j-agent-direct.tar.gz        （含 dist/release/logs 等未跟踪产物）
        └─ ARCHIVE.md                       （每个项目有什么、为何废弃、关键文件在哪、怎么取回）
  C2  三个 git 仓库各打一个 tag（如 archive/2026-11-04）
  C3  把归档路径与取回方法写进 qihang-ai-desktop 的 docs

阶段 D｜废弃（观察期后再物理删除）
  D1  D:/projects/qihang-code-approver  →  改名加 .archived 后缀，观察 1–2 周
```

> **为什么不直接 rm**：这四个项目里有三个带着**未提交**的改动、一个**完全没有 git**。
> 直接删等于丢掉 QihangAgentHub 全部内容（含全项目唯一的逐工具审批通道调研文档）和两个仓库的最新工作。
> 归档成本 ≈ 5 分钟，删除成本不可逆。

## 5. 废弃后 qihang-ai-desktop 的形态

```
启航AI工作台 qihang-ai-desktop（Electron 单组件，本地优先）
├─ 主功能：本地项目库 / pi agent 对话 / 任务 / 待办 / 笔记 / 数据源 / 技能
├─ 飞书面：Bot 对话 + 卡片交互 + 日报 + 【新增】审批卡片 + 【新增】任务完成卡片
├─ 移动面：中继（已有）+【可选】手机审批收件箱
├─ 智能体雷达（本项目原创）
│   ├─ 监控：8 工具只读采集 · 3s 探针 · 状态跃迁
│   ├─ 入库：指纹增量 · 本地 SQLite 正本 · FTS5 中文检索
│   ├─ 【新增】审批：票据状态机 + Claude Code hook 通道 + DSH 插件通道 + 收件箱
│   ├─ 【可选】观测态「疑似等授权」不可点卡
│   └─ 【可选】会话总结（pi agent summary_save）
└─ 数据：~/.qihang-ai-desktop/（radar.db + 主库 + config.json）
```

**一句话**：雷达从「本机 AI 工具的只读状态看板」升级为「本机 AI 工具的**审批中枢**」，
同时保持**不接管任何其它智能体的对话**。
