# 飞书连接指南

> 本文档说明如何把启航AI工作台连上飞书：从飞书开放平台的开通步骤、所需权限清单，到常见问题排查。
>
> 应用内的对应说明在「帮助」页的「📩 飞书 Bot」「📩 飞书卡片交互」板块；本文档是更完整的逐步指引。

## 先选对方式：两种接入，两条通道

| | 方式一：Webhook 群机器人 | 方式二：Bot（自建应用） |
|---|---|---|
| 能做什么 | **只发送**：AI 日报、提醒、任务通知推送到群 | **双向**：在飞书里和 AI 对话、下发任务、收结果卡片，也接收日报推送 |
| 需要什么 | 群里添加「自定义机器人」，粘贴一个 Webhook 地址 | 飞书开放平台创建自建应用，配权限 + 订阅事件 |
| 配置耗时 | 约 2 分钟 | 约 10 分钟（含发布审核） |
| 适合谁 | 只想把日报/提醒推进群 | 想在手机飞书里指挥电脑里的 AI |

两条通道互相独立，可任选或同时开启。**只想收日报选方式一即可；想对话、派任务必须配方式二。**

---

## 方式一：Webhook 群机器人（仅推送）

1. 在飞书里打开目标群 → 右上角「设置」→「群机器人」→「添加机器人」→ 选「**自定义机器人**」。
2. 填一个名字和描述（如「启航AI工作台」），安全设置任选其一（见下方说明），创建后**复制 Webhook 地址**（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxx`）。
3. 打开工作台「设置 → 📱 移动端 → 🔗 飞书 Webhook（群通知推送）」，粘贴地址并保存，点「**测试**」——群里应立即收到「启航AI工作台 桌面端连接测试成功！」。

**关于安全设置的说明**（当前版本按此选择，否则消息会被拦截）：

| 安全设置 | 是否支持 | 说明 |
|---|---|---|
| 自定义关键词 | ✅ 推荐 | 填一个你的推送里必出现的词（如「日报」或「提醒」）；不匹配的消息会被飞书拒绝 |
| 签名校验 | ❌ 暂不支持 | 应用当前不对 Webhook 请求加签，选了会发送失败 |
| IP 白名单 | ✅ 可用 | 填你电脑的出口公网 IP；IP 变动后需更新 |

配好 Webhook 后，以下内容会自动推送到群：每日 AI 日报、提醒触发、任务执行通知（任务勾选了「推送飞书」时）。

## 方式二：Bot 双向对话（自建应用）

### 第 1 步：创建自建应用

1. 登录[飞书开放平台](https://open.feishu.cn/)（用你的飞书账号）→ 进入「**开发者后台**」。
2. 点「**创建企业自建应用**」，填名称（如「启航AI工作台」）和描述，图标可上传 `docs/logo.png`。
3. 创建完成后，在应用首页左侧「凭证与基础信息」里找到 **App ID** 和 **App Secret**（稍后要填到工作台）。

### 第 2 步：添加应用能力「机器人」

左侧「**应用能力**」→「添加应用能力」→ 选择「**机器人**」。没有这一步，飞书里搜不到你的机器人。

### 第 3 步：开通权限

左侧「**开发配置**」→「**权限管理**」→ 搜索并开通以下 3 个权限（应用只有「接收消息 + 发消息」两个动作，权限最小化）：

| 权限 ID | 显示名 | 用途 |
|---|---|---|
| `im:message.p2p_msg:readonly` | 获取用户发给机器人的单聊消息 | 接收私聊里你发给机器人的消息 |
| `im:message.group_at_msg:readonly` | 接收群聊中@机器人消息 | 接收群里 @机器人 的消息 |
| `im:message:send_as_bot` | 以应用的身份发消息 | 发送回复文本与交互卡片（`im.message.create`） |

> 图省事也可以直接开通大权限 `im:message`（获取与发送单聊、群组消息），上述三条全部涵盖；本文按最小权限推荐。

### 第 4 步：订阅事件与回调（关键步骤）

左侧「开发配置」→「**事件与回调**」：

1. **订阅方式选「长连接」**（重要）。桌面端通过官方 SDK 出站建立 WebSocket 长连接接收事件，**没有公网域名、不填任何回调 URL**；如果选了「将事件发送至开发者服务器」会收不到任何消息。
2. 切到「**事件配置**」Tab →「添加事件」→ 搜索并订阅「**接收消息（`im.message.receive_v1`）**」。
3. 切到「**回调配置**」Tab →「已订阅的回调」→「添加回调」→ 订阅「**卡片回传交互（`card.action.trigger`）**」。
   - 这是**卡片按钮**（项目选择卡片、结果卡片「💬 接着问」）的回调；不订阅时按钮点击无响应，但回复序号 / `/项目 名称` 等文字指令照常可用。

### 第 5 步：发布版本

权限与事件配置好后**必须发布才生效**：

1. 左侧「**应用发布**」→「版本管理与发布」→「创建版本」。
2. 填版本号与更新说明，提交发布。企业自建应用通常由管理员审核（个人版/免审租户一般秒过）。
3. 审核通过、应用状态为「已启用」后继续下一步。

> **每改一次权限/事件/回调都要重新发布一个版本**，否则新配置不生效——这是飞书收不到消息最常见的原因。

### 第 6 步：在工作台里配置并启动

1. 打开工作台「设置 → 📱 移动端 → 📩 飞书 Bot（飞书内对话）」。
2. 填入第 1 步的 **App ID** 与 **App Secret**，保存，点「**测试**」验证凭据有效。
3. 启动 Bot 服务（保存后自动启动；侧边栏引擎状态弹层里「飞书 Bot」应显示「已连接」）。

### 第 7 步：开始使用

- **私聊**：飞书顶部搜索机器人名字 → 进入单聊 → 直接发消息。
- **群聊**：把机器人拉进群 → **@机器人** 发消息（群聊只响应 @，不 @ 不会回复）。
- 收到消息后会先弹「📂 请选择项目」卡片（多项目时），点按钮即派活；结果卡片上点「💬 接着问」可继续追问。

## 卡片交互速查

详细交互设计见《[功能设计与使用说明](功能设计与使用说明.md)》5.5 节，这里只列命令：

| 操作 | 怎么做 |
|---|---|
| 指定项目（按钮之外的方式） | 回复序号 `2` 或 `/项目 2`；回复 `/项目 项目名`；消息开头写项目名；行内标记 `[笔记库：项目名]`（只对当条生效） |
| 继续上一个话题 | 点结果卡片「💬 接着问」后直接回复（30 分钟滑动窗口内有效）；或回复 `继续 <要求>` 接最近一条对话 |
| 开始新话题 | 发 `/` 开头的命令，或点项目选择卡片按钮 |

## 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| Bot「测试」通过，但发消息机器人不回 | 事件未订阅、未发布版本、订阅方式不是「长连接」 | 按第 4 步检查三项，然后**重新发布版本**并重启工作台 |
| 群里 @机器人 没反应，私聊正常 | 未开通 `im:message.group_at_msg:readonly` | 第 3 步补权限 → 重新发布 → 重启 |
| 卡片按钮点了没反应 | 未订阅「卡片回传交互（`card.action.trigger`）」 | 第 4 步第 3 小步订阅回调 → 重新发布 → 重启；期间可回复序号 / `/项目 名称` |
| 点按钮提示「目标回调服务超时未响应」 | 旧版本应用把任务执行等在了回调里，超过飞书 3 秒时限 | 升级/重启本应用；该报错不代表任务没执行——出现「已接单」即已派活，结果卡片稍后送达 |
| 机器人无法发送任何消息 | 缺 `im:message:send_as_bot` 或应用未发布/未启用 | 第 3、5 步检查；运行日志页过滤 `[Feishu]` 可看到接口报错详情 |
| Webhook 测试失败 | 地址粘错 / 安全设置拦截 | 核对 URL；若开了「签名校验」请改为「自定义关键词」；关键词不匹配时换一个必出现的词 |
| 收不到日报/提醒推送 | 只配了 Bot 没配 Webhook | 日报与提醒推送走 **Webhook** 通道，按方式一配置 |
| 应用发布后搜不到机器人 | 未添加「机器人」能力，或不在可见范围 | 第 2 步补能力；检查应用的可用范围（默认仅本人可用则搜的时候用自己的账号） |
| App Secret 泄露了怎么办 | — | 开放平台「凭证与基础信息」重置 Secret，然后在工作台里更新 |

## 安全与隐私

- App ID / App Secret 保存于本机 `config.json`（已加入 `.gitignore`），不上传任何服务器。
- 长连接模式为**出站**连接，桌面端不监听任何端口、无需公网 IP，家庭/公司网络内网环境可直接使用。
- 飞书侧收到什么取决于你发什么：对话内容会发给你所配置的模型服务商用于生成回复（离线方案见 README「数据与隐私」）。
